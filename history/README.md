## 后续同步

在主工程根目录执行：

```bash
python3 scripts/sync_history_versions.py --dry-run
python3 scripts/sync_history_versions.py
git add history
git commit -m "Sync historical source snapshots"
git push
```

默认来源为 `../历史版本/`，也可用 `--source /实际路径/历史版本` 指定。脚本发现新的完整工程子目录后会一并收录，并自动更新本索引。

同步会更新已有快照，并移除来源中已删除、且快照里没有被另行修改的受管理文件。未出现在旧清单里的文件和来源中缺失的整个版本目录会保留。如果快照文件有独立的本地改动，脚本会停止，防止覆盖；应先处理这些改动。脚本不会自动提交或推送。

需要运行旧版本时，可将对应子目录复制到单独的工作区，补齐该版本的模型和环境后重新构建。本次同步只验证文件完整性，未运行历史版本的机器人程序。
