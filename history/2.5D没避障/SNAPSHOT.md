# 历史源码快照：2.5D没避障

来源为上一级 `历史版本/2.5D没避障/`。目录名称按原样保留，不代表本次验证过该版本的功能或可运行性，也不据此推断版本先后顺序。

原始代码、配置模板、测试和项目说明按文件内容保存；模型、环境、编译产物、地图、历史报告、备份、嵌套 Git 元数据与忽略规则及上游大体积演示资料未收录。每个快照统一使用主工程的 `.gitignore`，以免上游规则遗漏已收录源码。原目录中的文件不会被此同步过程修改或删除。

资源需求以本版本的源码和 `.env.example` 为准；主工程的 [本地资源说明](../../docs/LOCAL_RESOURCES.md) 可作为部署参考。旧说明中指向已排除备份、报告或本机绝对路径的链接可能不可用。

`SOURCE_MANIFEST.json` 记录所收录文件的 SHA-256、大小和执行权限。后续请修改原历史目录，再从主工程执行 `python3 scripts/sync_history_versions.py`。
